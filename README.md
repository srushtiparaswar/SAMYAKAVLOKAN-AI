# 🛡️ SAMYAKAVLOKAN AI
Women Safety Surveillance System using YOLOv8, OpenCV, SQLite, Streamlit and Twilio.

## Features
- Real-time Person Detection
- Real-time Object Detection
- Help Gesture Alert System
- Email Alert Notification
- SMS Alert Notification (Twilio)
- Event Logging using SQLite
- Streamlit Dashboard
- Event Analytics

## Technologies Used
- Python
- YOLOv8
- OpenCV
- SQLite
- Streamlit
- Twilio
- Git & GitHub

## Project Modules
1. Person Detection
2. Object Detection
3. Help Gesture Detection
4. Alert System
5. Database Logging
6. Dashboard Analytics
